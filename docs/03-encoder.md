# Энкодер и логическая координата

## Действующая модель

PCF8574 → декодирование ACE-128 → нормализация → калибровка → фильтрация → ClockTracker → рабочая логика.

Нормализация floor(raw*65536/resolution), угол 0..65535; один оборот 65536, полный цикл C=786432, координата 0..786431 (12:00 = 0). ACE-128 шаг 512, будущий AS5600 шаг 16, 256 позиций — 256. Нормализация не повышает физическую точность. Циклическая кратчайшая разность, ровно половина оборота неоднозначна. Обновление логической координаты по модулю C; никаких бесконечных накопителей и сбросов истории при переходе через ноль. Инвариант при известном часе: clockPosition % 65536 == confirmedCalibratedAngle; сам по себе он не доказывает правильность часа.

## Калибровка

**Необязательна (решение 26.11.2026).** При отсутствии сохранённого смещения используется ноль; отсутствие калибровки само по себе не блокирует MANUAL или AUTO. Оператор отвечает за соответствие стрелок показаниям. Не вводить дополнительный постоянный флаг или обязательный процесс после перезапуска. Существующее сохранение смещения и диагностический признак calibration_saved остаются.

Оператор выставляет минутную стрелку на текущую минуту, затем нажимает «Откалибровать». Условия: OFF/MANUAL, мотор остановлен, нет аварии/перехода, энкодер healthy, свежий NTP. Guard по умолчанию запрещает секунды 50–59, разрешает 00–49; сервер повторно проверяет. Целевая позиция внутри диапазона floor(pos*60/128)==minute; offset=(target+128-raw)%128. В нормализованных единицах offset*512 для ACE-128. Идентичное сохранённое смещение не записывать и не журналировать; кнопка «Откалибровано». При ошибке записи действующее смещение не изменять.

При изменении смещения перебазировать подтверждённый угол без фиктивного движения; логический час становится неизвестным и требует новой ручной привязки. Никакого восстановления часа по совпадению минут с NTP. Raw используется только для декодирования, калибровки и диагностики.

## Достоверность и движение

Различать INITIALIZING, VALID, SUSPICIOUS, INVALID, непрерывность наблюдения и известность часа. Отклонённый отсчёт не становится опорой. Подтверждать одинаковые последовательные отсчёты; число чтений задаётся encoderStableSamples. Ограниченный бюджет скорости не выдаётся заново на каждом опросе. При небольшом обратном отклонении удерживать опору; возвращение к ней не считать продвижением. Большое или длительное отклонение — подозрение. Ограничить время непрерывного неподтверждённого состояния, даже если меняются виды аномалий/кандидаты; не перезапускать тайм-аут от каждой ошибки. Учитывать дискретность первого шага после инициализации и перекалибровки. Потеря I²C немедленно инвалидирует наблюдение; разрыв опроса лишает непрерывности. При короткой аномалии запрет новых запусков, ограниченное продолжение уже начатого движения до потери достоверности. Восстановление требует подтверждений, не сбрасывает аварию автоматически.

## Логический час

После запуска час неизвестен. Оператор задаёт фактический час 0..11 (0 отображать как 12) в MANUAL при остановленном моторе, здоровом датчике, без перехода/аварии. Минуты берутся из подтверждённого откалиброванного угла. Час обновляется по подтверждённым delta через откалиброванный ноль, в том числе в MANUAL. Краткая аномалия сама по себе не уничтожает час, потеря непрерывности уничтожает. После восстановления данных или перезагрузки нужна ручная привязка. Координата хранится в RAM.

## Реализация и незакрытые проверки

26d079c: цепочка уже использует откалиброванный угол до фильтра, ClockTracker интегрирован; поддержаны подтверждения и ограничение разрыва опроса. Остались проверка бюджета первого шага, смешанных аномалий и возраста подтверждения, реальная интеграция reader/filter/tracker/motor, диагностика и стенд. Настоящее движение AS5600 не реализовано; тесты математики для 4096 позиций не означают поддержку датчика.

### Исправление тайм-аута и начального бюджета

Единый таймер начинается при первом неподтверждённом отсчёте и сбрасывается только при принятом наблюдении; смена кандидата, обратное отклонение и отсутствие отсчёта не продлевают срок. При достижении 500 мс наблюдение недостоверно. При инициализации ACE-128 выдаётся однократный кредит одного физического шага (512), ограниченный ёмкостью бюджета, поскольку начальный угол может находиться на границе дискретизации. Перекалибровка сохраняет остаток бюджета, не выдаёт новый кредит и не считается движением. Стендовые параметры не изменены. Добавлены регрессионные тесты; статус CI фиксируется после проверки.

Повторный аудит: reader теперь вызывает rebase вместо создания нового фильтра при изменении смещения. Сохранение первого нулевого offset без изменения угла не сбрасывает час. Диагностика Serial различает invalid ACE, I2C read failed, потерю наблюдения и инициализацию; повторный поиск через 5 с после ошибки I2C. Физический стенд: шаг 5–6 с соответствует ожидаемому диапазону 5,15625–6,09375 с; быстрые отдельные шаги допустимы в пределах накопленного кредита.

## AS5600 — экспериментальная ветка

0x36, STATUS 0x0B и RAW ANGLE 0x0C–0x0D по ams DS000365. MD=1, ML/MH=0. Конфигурация и OTP не записываются. Разрешение 4096, шаг 16. Предварительные параметры: deadband ±32, бюджет 128, начальный кредит 48, обратный допуск 64. Подтверждаются близкие возрастающие кандидаты. ACE параметры неизменны. При нескольких адресах блокировка, смена типа после обнаружения требует перезапуска. AS калибровка отдельно по адресу 88, ACE по 80. Параметры AS требуют стенда.
