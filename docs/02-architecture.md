# Архитектура, контракты и хранение

UI → REST API → прикладной Controller → узкие аппаратные контракты → реализации. Математика положения независима от Arduino и конкретного датчика. Четыре ESP автономны; будущие внешние интеграции не заменяют местные защиты.

| Модуль | Ответственность |
|---|---|
| LuchClock.ino | Порядок setup/loop, координация жизненного цикла |
| src/application/controller.* | Режимы, команды, разрешения, снимок состояния |
| src/application/hardware.* | IEncoder, IMotor, ITimeProvider, INetworkStatus, ICalibration и адаптеры |
| src/application/event_logger.* | Кольцевой журнал в RAM |
| src/encoder/ | Чтение, декодирование, калибровка, фильтрация и логическая координата |
| src/motor/ | GPIO, таймеры, защитная остановка |
| src/network/ | Wi-Fi, системное время, возраст синхронизации |
| src/storage/ | IStorage, байтовый доступ EEPROM |
| src/system_settings.* | Значения, пределы, проверка, применение и сохранение |
| src/web/ | HTTP и отображение; не источник управляющих решений |

Существующие статические адаптеры допустимы. Не переводить всё в классы ради ООП; улучшать подменяемость зависимостей там, где нужна проверка. Не ослаблять обязательные защиты. Сырые показания не использовать в рабочей логике. Доступность действий вычисляет сервер; UI только отображает её и выполняет запросы.

## API v1

GET /, /api/status, /api/events, /api/settings. POST /api/mode?value=off|manual|auto, /api/command?action=forward|stop, /api/settings (apply/save), /api/calibration, /api/clock-hour?hour=0..11, /api/reset-fault. Реверс не поддерживается. Успех JSON ok:true; ошибка ok:false, code, message (400/409/500). Версии прошивки и API задаются в config.h.

Снимок состояния содержит режим и разрешения, здоровье/достоверность энкодера, известность часа, координату, время, NTP, состояние привода, таймеры и аварии. clock_position достоверна только при clock_hour_known; encoder_position и encoder_minutes — откалиброванные подтверждённые значения; encoder_raw и encoder_raw_position — диагностика. API пока без авторизации: не открывать в интернет, ограничить сеть; авторизация/CSRF до эксплуатации.

## Настройки и EEPROM

Единый источник изменяемых таймингов и диапазонов — system_settings.h, PUBLIC_SETTINGS определяет публичные поля. RAM apply, save одновременно применяет и сохраняет; проверка на сервере, при ошибке commit откат RAM и буфера. Идентичные записи не повторять. Формат v3: 64 байта с magic/version/checksum; миграция v1/v2 в RAM, запись при явном save. Калибровка отдельная запись по адресу 80, общий объём 128 байт. Не менять формат без необходимости; не добавлять новый флаг обязательности калибровки. EEPROM эмулируется во flash, откат буфера не гарантирует сохранность при пропадании питания во время commit. Логический час и журнал не записывать во flash.

Скрытые фиксированные интервалы: Wi-Fi диагностика 15 с, поиск PCF8574 5 с; старые поля EEPROM сохранены. ntpRequestSec не используется, сохранён для совместимости v3. autoStepMin пока резерв для будущего AUTO.

## Открытые задачи v1.19

Интеграционные тесты реальных рабочих компонентов; убрать зависимость защиты двигателя от raw, согласовать серверное разрешение установки часа, диагностику и состояние API. Прямые обращения к времени в калибровке/журнале и общие типы в аппаратных заголовках — точки улучшения, не повод для полной переработки. Проверить оставшийся SIMULATION_MODE и мёртвые ветки реверса; не менять внешний контракт без причины.

Контракт IEncoder::encoderConfirmedAngle возвращает нормализованный подтверждённый откалиброванный угол (int32_t, -1 при недостоверности). Двигатель использует его для контроля движения вместо сырой позиции; шаг ACE-128 не теряет разрешение. Калибровка получает локальное время через ITimeProvider.
