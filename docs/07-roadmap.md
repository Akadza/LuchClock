# Границы текущей разработки и дальнейшие этапы

## v1.19 — только завершение интеграции

Исправления фильтра, достоверность и логическая координата, согласование контроллера/двигателя/API/UI, интеграционные тесты, автоматическая сборка ESP8266, документация и подготовка стенда. Не расширять функциональность.

## После v1.19

- AS5600 в отдельной ветке после проверки ACE-128. Все 4096 позиций сохраняются, качество магнитного поля и ошибки связи проверяются драйвером; пороги шума по измерениям. Формат/миграция калибровки отдельно.
- AUTO: целевая позиция обновляется каждые 2 минуты (предварительно); выбор ожидания или движения вперёд по 12-часовой координате и оценке времени. Никакого реверса. Предварительные ориентиры 3 ч предупреждение, более 4 ч блокировка — трактовку круговой ошибки согласовать. Без обхода 15-минутного лимита; стратегия больших коррекций и возобновления после аварии/NTP отдельно.
- Настройка скорости: motorMsPerDialMinute предварительно 12000, UI в секундах. Явный операторский сеанс измерения 10–15 мин: msPerMinute=runMs*65536/(distance*60), 64-битные вычисления, только подтверждённое перемещение. Отклонять сеанс при потере непрерывности/ошибках/остановках, не менять активные настройки в ходе измерения, результат применить/сохранить после проверки. Не ослаблять защиту самонастройкой.
- Ручные таймеры: удержание остановки либо движение заданное время с последующим AUTO; только при соблюдении всех защит. Отмена, лимиты, перезапуск и UI согласовать отдельно.
- Центральный сайт четырёх автономных ESP, сравнение координат по общей шкале с учётом времени измерения и достоверности, Zabbix, хранение событий 2–3 дня. Программное считывание и межконтроллерная синхронизация — отдельные заменяемые модули.
- Авторизация/CSRF и сетевые ограничения до эксплуатации. Измерения heap/loop и uptime за 49,7 суток, дальнейшее упрощение по измерениям. LittleFS — не текущий этап.

Не возвращать отвергнутые решения: реверс, отдельный режим UPS/датчик силового питания, скользящий лимит двигателя, обязательная калибровка, запись логической координаты каждого шага во flash.
