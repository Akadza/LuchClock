# LuchClock

Контроллер башенных часов на ESP8266 с ACE-128 через PCF8574, локальным веб-интерфейсом и NTP. Двигатель только вперёд, безопасный старт OFF. Четыре независимых устройства. AS5600 и автоматический алгоритм движения — будущие этапы.

Актуальные требования, статус, ограничения и история: [спецификация](docs/LuchClock-specification.md). Для рабочей ветки feature/encoder-v1.19 — кандидат v1.19, не готов к эксплуатации до стенда. Статус других веток определять по их документации и config.h.

## Сборка

Arduino IDE или Arduino CLI, NodeMCU 1.0 (ESP-12E), ESP8266 core 3.1.2 — проверенный CI baseline. Скопировать secrets.example.h в локальный secrets.h, заполнить Wi-Fi, задать уникальные DEVICE_NAME и DEVICE_HOSTNAME в config.h. Не коммитить secrets.h. Открыть LuchClock.ino, выбрать плату и порт. Serial 115200. Автоматическая сборка и host-тесты в .github/workflows.

Перед подключением силовой части выполнить [стендовый протокол](docs/08-bench-protocol.md) и проверить аппаратную безопасность. API без авторизации, не публиковать в интернете.
